# AI Phishing Detection for WhatsApp Web

## Folder Contents

**chrome_extension** - Contains all the code for the chrome extension

**backend** - Contains backend python code required for the chrome extension

**phishing_detector** - Contains all the code for the console version of the app, and the datasets used in both versions

## Download Instructions

**1.** Download full GitHub contents onto your device

**2.** Unzip the file

**3.** Go to Manage Extensions on Google Chrome and select Developer Mode

**4.** Click Load unpacked and select the chrome_extension folder

**5.** Run the backend.exe file loacted in the backend\dist folder
